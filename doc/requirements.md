# 경기 버스 길찾기 (mybus-route) — 요구사항과 제반사항

- 처음 작성: 2026-11-18 / 전체 갱신: 2026-11-25 (카카오맵 전환, ADR-044 반영)
- 결정의 근거는 [adr.md](adr.md)에 있다. 이 문서는 "지금 무엇을 하는 서비스이고, 운영하려면 무엇이 필요한가"를 한곳에 모은 것이다.

## 1. 개요

| 항목 | 내용 |
|---|---|
| 서비스 이름 | 경기 버스 길찾기 (영문 mybus-route) |
| 주소 | https://mybus-route.copark-ai.workers.dev |
| 저장소 | GitHub `copark-eng/mybus-route` (Public) |
| 목표 | 출발지·도착지를 고르면 경기도 버스 실시간 정보로 지금 출발했을 때 빠르고 합리적인(요금 포함) 경로를 추천한다 |
| 지역 | 경기도 전체. 노선 약 3,160개, 정류장 약 41,000곳(출발·도착으로 고를 수 있는 경기도 정류장 약 38,300곳) ([ADR-027](adr.md#adr-027)) |
| 이용 형태 | 회원가입 없음. 휴대폰 브라우저 우선 ([ADR-014](adr.md#adr-014)) |

## 4. 외부 서비스·계정

### 4.1 공공데이터포털 (data.go.kr) — 인증키 하나(`BUS_API_KEY`)
| 서비스 | 용도 | 호출 위치 | 이용허락 |
|---|---|---|---|
| 경기도_버스도착정보 조회 (`busarrivalservice/v2`) | 정류장별 실시간 도착 | Worker `/api/arrivals` | 공공누리 1유형 |
| 경기도_버스위치정보 조회 (`buslocationservice/v2`) | 노선의 운행 중 버스 위치 | Worker `/api/bus-locations` | 공공누리 1유형 |
| 경기도_버스 기반정보 조회 (`baseinfoservice`) | 노선·정류소·노선별 정류소 파일 | `npm run build:db`(로컬) | 공공누리 1유형 |
| 기상청_단기예보 조회서비스 (`VilageFcstInfoService_2.0`) | 초단기실황·단기예보 | Worker `/api/weather` | 공공누리 1유형 |

- 개발계정은 일일 호출 한도가 있다. **운영계정(트래픽 증가) 신청이 필요하다.** 버스도착정보부터 신청한다.
  - 신청 서비스명: 경기 버스 길찾기
  - URL: 위 주소
- 한도를 넘으면 Worker가 `429 DAILY_LIMIT`을 돌려주고, 10분 동안 다시 부르지 않는다. 화면에는 안내 문구를 띄운다.

### 4.2 카카오 개발자센터 (developers.kakao.com)
| 항목 | 설정 |
|---|---|
| 앱 | 경기 버스 길찾기 |
| JavaScript 키 | 지도 표시. **[앱] → [플랫폼 키] → [JavaScript 키] → [JavaScript SDK 도메인]**에 `http://localhost:5173`, `https://mybus-route.copark-ai.workers.dev`를 등록한다. "제품 링크 관리"가 아니다 |
| REST API 키 | 주소 검색(`/v2/local/search/address`), 좌표→주소(`/v2/local/geo/coord2address`). 서버에서만 쓴다 |
| 제품 설정 | 카카오맵 사용 설정 ON |
| 유료 API | **켜지 않는다.** 무료 쿼터를 넘으면 과금 없이 429로 멈춘다 |

### 4.3 Cloudflare
| 항목 | 내용 |

| Worker 이름 | `mybus-route` (workers.dev 주소, preview URL 끔) |

### 4.4 GitHub
- 저장소 `copark-eng/mybus-route`. push로 자동 배포하는 설정(Workers Builds)은 쓰지 않는다. 배포는 로컬에서 `npm run deploy`로 한다.

## 5. 비밀값·설정 파일 (git에 올리지 않음)

| 파일 | 변수 | 내용 |
|---|---|---|
| `web/.env` | `VITE_KAKAO_MAP_KEY` | 카카오 JavaScript 키. 빌드 때 화면 코드에 들어간다(공개 키) |
| `worker/.dev.vars` | `BUS_API_KEY` | data.go.kr 인증키(Encoding/Decoding 어느 쪽이든) |
| `worker/.dev.vars` | `KAKAO_REST_KEY` | 카카오 REST API 키 |

- 예시 파일: `web/.env.example`, `worker/.dev.vars.example`
- 배포 환경: 비밀값은 Cloudflare 비밀값으로 넣는다. `VITE_KAKAO_MAP_KEY`는 로컬 빌드 때 `web/.env`에서 읽는다. Workers Builds를 쓰게 되면 대시보드 빌드 변수에 넣는다.
- `private/`, `.env`, `.dev.vars`는 커밋하지 않는다. 키 값은 채팅·로그에 출력하지 않는다.

## 6. 개발·배포

### 6.1 환경
- Node.js 24, npm workspaces(`web`, `worker`)
- 주요 버전: React 19, Vite 8, TypeScript 7, Vitest 5, Wrangler 4

### 6.2 명령
| 명령 | 내용 |
|---|---|
| `npm run dev:worker` | Worker 로컬 실행(8787) |
| `npm run dev:web` | 웹 로컬 실행(5173, `/api`는 8787로 전달) |
| `npm test` | 웹·Worker 테스트 |
| `npm run build` | 웹 빌드 + Worker 타입 검사 |
| `npm run deploy` | 빌드 후 Cloudflare 배포 |
| `npm run build:db` | 정류장·노선 DB와 노선 형상 다시 만들기 |

### 6.3 배포 순서
1. `npm test` → `npm run build`, 로컬 브라우저에서 확인
2. 커밋. push는 사용자에게 확인한다.
3. `npm run deploy` (사용자가 요청할 때만)
4. 확인: `version.json`의 빌드 시각, 주요 API(`/api/arrivals`, `/api/geocode`), 지도 표시

이미 열린 화면에는 새 버전 알림이 뜬다(ADR-034).

### 6.4 데이터 갱신
- `npm run build:db`
  - 경기도 버스기반정보로 그날 파일을 받아 `web/public/data/{stations,routes}.json`(압축 v2)과 `web/public/data/lines/<노선ID>.json`(형상)을 만든다.
  - 받은 파일은 `scripts/.cache/baseinfo`에 보관한다. 정류장 수가 20% 넘게 줄면 기존 파일을 지킨다.
- 갱신 후 커밋·배포해야 반영된다. 주간 자동 갱신(GitHub Actions, ADR-016)은 아직 만들지 않았다.

## 7. 호출 관리 (공공데이터 한도)

| 대상 | 화면 갱신 | Worker 캐시 | 비고 |
|---|---|---|---|
| 도착정보 | 검색 결과 60초, 상세·즐겨찾기 30초 | 30초(캐시 나이 `X-Data-Age`로 남은 시간 보정) | 자동 갱신은 위쪽 4개 경로만. 하차 정류장은 3분 안 값 재사용 |
| 버스 위치 | 노선 화면 30초 | 20초 | |
| 날씨 | 화면 열 때 | 기상청 발표 단위(실황 1시간, 예보 3시간) | 격자별 시간당 약 1.3회 |
| 주소 검색 | 입력 300ms 뒤, 주소처럼 보일 때만 | 없음 | 카카오 쿼터 |

- 5분 넘게 조작이 없거나 화면이 안 보이면 자동 갱신을 멈춘다.
- 사용량은 Workers Logs의 한 줄 로그(api, 화면, 캐시 여부, 상태)로 본다.
- `*.workers.dev`에서는 Cloudflare 지역 공유 캐시가 동작하지 않는 것으로 보인다. 커스텀 도메인을 붙이면 캐시 효과가 커진다.

## 9. 제약사항

- C-1. 도착정보 API는 노선별 다음 버스 2대까지만 준다. 그 뒤는 배차 간격으로 추정한다.
- C-2. 정류장 사이 탑승 시간은 API가 주지 않는다. 같은 차량을 하차 정류장에서 찾거나, 거리×속도(6m/s)+정차(20초)로 추정한다.
- C-3. 출발·도착과 환승은 경기도 정류장만 쓴다. 서울·인천 정류장은 노선 경로로만 쓴다.
- C-4. 환승은 1회까지. 지하철은 없다(검토: [subway-review.md](subway-review.md)).
- C-5. 요금은 정류장 직선거리로 계산한 추정값이다. 마을버스는 성남 기준(1,550원)이다.
- C-6. data.go.kr 개발계정과 카카오 무료 쿼터의 일일 한도가 있다.
