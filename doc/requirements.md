# 버스 경로 추천 웹서비스 — 요구사항

- 작성일: 2026-11-18
- 상태: 초안 (미결 항목은 [decisions.md](decisions.md) 참고)

## 1. 목표
출발 정류장과 도착 정류장을 선택하면 경기도 버스 실시간 정보를 바탕으로 **지금 출발했을 때 가장 빨리 도착하는 경로**를 추천한다. 직행과 환승 경로를 함께 비교한다.

## 2. 기능 요구사항

### FR-1. 출발지·도착지 선택
| ID | 내용 |
|---|---|
| FR-1.1 | 네이버 지도에 정류장 마커를 표시하고, 마커를 클릭해 출발지/도착지로 지정할 수 있다. |
| FR-1.2 | 입력창에 정류장 이름 또는 정류장 번호(예: `07015`)를 입력해 선택할 수 있다. |
| FR-1.3 | 입력창은 자동완성을 지원한다 (이름 일부 일치, 정류장 번호 일치; 초성 검색은 선택). |
| FR-1.4 | 같은 이름의 정류장은 정류장 번호와 진행 방향(다음 정류장)으로 구분해 보여 준다. |
| FR-1.5 | 출발지와 도착지를 서로 바꾸는 버튼을 제공한다. |
| FR-1.6 | 주소로도 출발지·도착지를 지정할 수 있고, 근처 정류장(반경 500m)까지 걷는 시간을 경로에 포함한다. 장소 이름 검색은 지원하지 않는다 ([ADR-013](adr.md#adr-013), [ADR-019](adr.md#adr-019)). |
| FR-1.7 | 지도에서 정류장이 아닌 위치를 눌러 출발지·도착지로 지정할 수 있다 ([ADR-013](adr.md#adr-013)). |

### FR-2. 정류장 DB
| ID | 내용 |
|---|---|
| FR-2.1 | 정류장 정보(stationId, 정류장 번호, 이름, 좌표, 경유 노선)를 보유한다. |
| FR-2.2 | 노선별 정류장 순서(경로 탐색용)를 보유한다. |
| FR-2.3 | DB는 필요 시 및 정기적으로 갱신할 수 있어야 한다. |

### FR-3. 출발지·도착지 저장
| ID | 내용 |
|---|---|
| FR-3.1 | 선택한 출발지·도착지 쌍을 브라우저에 저장한다. |
| FR-3.2 | 저장된 쌍을 클릭하면 즉시 실시간 경로 추천을 실행한다. |
| FR-3.3 | 저장된 쌍을 삭제할 수 있다. |

### FR-4. 실시간 경로 추천
| ID | 내용 |
|---|---|
| FR-4.1 | 검색 모드로 **직행만** / **환승 포함**을 선택할 수 있다. |
| FR-4.2 | 결과는 **최종 도착 예정 시각이 빠른 순**으로 정렬한다. 환승 경로가 더 빠르면 직행보다 위에 둔다. |
| FR-4.3 | 각 경로에 출발 정류장 대기 시간(실시간), 탑승 시간, 최종 도착 예정 시각, 총 소요 시간을 표시한다. |
| FR-4.4 | 환승 경로는 추가로 환승 정류장 도착 예정 시각, 환승 도보 시간, 환승 정류장 대기 시간을 표시한다. |
| FR-4.5 | 출발 정류장의 실시간 도착 예정 시간(노선별 다음 버스 2대)을 함께 보여 준다. |
| FR-4.6 | 추정값(실시간 예측이 아닌 값)은 화면에서 구분해 표시한다. |
| FR-4.7 | 자동 갱신과 수동 새로고침을 지원한다. |

### FR-5. 즐겨찾기
| ID | 내용 |
|---|---|
| FR-5.1 | 추천 결과에서 선택한 노선(경로)을 즐겨찾기로 저장한다. |
| FR-5.2 | 즐겨찾기 목록에서 해당 노선의 실시간 도착 정보를 바로 볼 수 있다. |
| FR-5.3 | 즐겨찾기를 삭제할 수 있다. |

## 4. 데이터 출처
data.go.kr 경기도 버스 API, 텔레그램 봇과 같은 인증키 사용 ([ADR-005](adr.md#adr-005)).

| 용도 | 서비스 | 활용신청 |
|---|---|---|
| 실시간 도착 | 경기도_버스도착정보 조회 | 승인됨 |
| 정류장 목록·좌표 | 경기도_정류소 조회 | **필요** (현재 403) |
| 노선별 정류장 순서 | 경기도_버스노선 조회 | **필요** |
| 버스 위치 (선택) | 경기도_버스위치정보 조회 | 선택 |

## 5. 제약사항
- C-1. 도착정보 API는 노선별 **다음 버스 2대**까지만 예측을 준다. 그 이후는 배차 간격으로 추정해야 한다.
- C-2. 정류장 간 **탑승 시간은 API가 직접 제공하지 않는다** ([ADR-008](adr.md#adr-008)).
- C-3. 경기도 데이터만 사용하므로 서울 버스·서울 정류장은 포함되지 않는다.
- C-4. data.go.kr 개발계정은 일일 호출 수 제한이 있다.
- C-5. 네이버 지도는 NCP에 애플리케이션과 서비스 URL을 등록해야 한다.

## 6. 진행 단계 (안)
1. MVP: 정류장 DB, 자동완성, 지도 선택, 출발 정류장 실시간 도착, API 프록시, 배포
2. 직행 경로 추천, 출발지·도착지 저장
3. 환승 경로, 탑승·환승 시간 계산, 도착 시각 순 정렬
4. 즐겨찾기, 자동 갱신, 정류장 DB 자동 업데이트
